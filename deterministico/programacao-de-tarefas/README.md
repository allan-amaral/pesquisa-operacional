# Programação de Tarefas

Esta pasta contém implementações relacionadas a problemas de programação de tarefas. Os algoritmos estão organizados de acordo com diferentes ambientes de máquinas, por exemplo:

- Máquina única
- Máquinas paralelas
- Flow shop
- Job shop
- Open shop

Dentro de cada ambiente, os arquivos podem estar organizados, por exemplo, em:

- Modelos exatos
- Heurísticas
- Gerador de instâncias
